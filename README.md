# E-ksena Workspace

This repository contains two Node.js projects:

- `E-ksena_Backend` (Express + Supabase)
- `E-ksena-webapp-all-files` (Expo app)

## Install all dependencies

Run once from the repository root:

```bash
npm run install:all
```

## Start both projects

```bash
npm start
```

## Useful scripts

- `npm run start:web` - starts backend + Expo web mode
- `npm run start:backend` - starts backend only
- `npm run start:frontend` - starts frontend only

## Backend standalone

You can now run backend directly with:

```bash
cd E-ksena_Backend
npm start
```
